# 🧾 InvoMate – Smart Billing & Business Management System

InvoMate is a modern, scalable **business management and invoicing platform** built using the **MERN stack**.  
It helps small shop owners and businesses manage products, customers, billing, and insights — all in one place.

> Built with a focus on real-world usability, security, and clean architecture.

---

## 🚀 Features

### 🔐 Authentication & Security
- User registration & login
- JWT-based secure sessions

### 📦 Product Management
- Add, update, delete products

### 🧾 Invoice & Billing System
- Create professional invoices
- Auto invoice number generation
- GST/Tax calculation
- Discount support
- Convert invoices to **PDF**
- Sends the PDF to user on WhatsApp
- Download & share invoices

---

### Frontend
- **React.js**

### Backend
